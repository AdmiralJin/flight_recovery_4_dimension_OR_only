# Workbench v3 设计规则

适用：航空恢复科研工作台，React 桌面优先，兼容窄屏，浅深色成对维护。任务1的三个工作区及保存、校验、运行顺序已验收，不在视觉阶段重新设计业务流程。

## 依据与取舍

UI/UX Pro Max 2.15.0，固定 commit `b7d5353e0130feb8c5574ef1251f8a1db1873ccb`。安装来源与文件 hash 见 `docs/ui/workbench_v3_skill_source.json`。

- `research analytics dashboard` / `internal analytics dashboard` 的产品命中 **Analytics Dashboard**、风格命中 **Minimalism & Swiss Style**、字体命中 **Dashboard Data**，适用于当前研究工具。
- 同一生成器给出的 **Enterprise Gateway** 是营销首页结构；缩窄检索后仍不适用，未持久化或采用该部分。工作区结构沿用已验收设计，不从营销模板推断。
- `tabular data numerals` 命中 Dashboard Data：正文与数字 / 代码区分。采用本机中文无衬线与等宽字体后备，不新增在线字体请求；数字使用 tabular-nums。
- `error summary validation` 命中 Focusable Error Summary：失败提示可聚焦、保留字段错误，弹窗内也能看到错误。
- React 首次 `dense tables rerender` 无命中，缩窄为 `virtualize list` 后命中 Virtualize long lists；保留现有 TanStack 虚拟化，不按搜索结果切换框架。
- 图表检索只采用与数据类型相符的结果。多变量雷达图不适用于上下界时间序列，保持阶梯线、成本柱图、延误柱图及资源甘特。

## 全局规则

| 项目 | 规则 |
|---|---|
| 色彩 | 中性灰白 / 深蓝灰表面；海军蓝主动作；绿表示可行 / 恢复，琥珀表示风险，红表示错误 / 取消 |
| 排版 | 标题 28–30px；正文 14px，移动正文及输入 16px；表格 13px、辅助信息 12px；短元信息允许更小 |
| 数字 | 等宽数字、统一小数格式和单位；不把未知值写成 0；完整值可在表格和证据中查看 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32px；页面、卡片、表单分别使用稳定层级 |
| 控件 | 桌面 40px、窄屏至少 44px；悬停 / 按下 / 禁用 / 加载 / 焦点分别可辨，按下不改变布局 |
| 表格 | 标识符优先，虚拟化、水平滚动限于表格容器；首列便于追踪；普通编辑不开放 ID |
| 图表 | 文字不少于 12px；图例有文字，LB / UB 用不同线型；保留数据表与证据作为非颜色的读取途径 |
| 主题 | 普通文字至少 4.5:1；关键控件与焦点至少 3:1；两套主题分别截图和自动检查 |
| 动效 | 小范围 150–200ms；遵从 reduced-motion；不引入 GSAP 或装饰性动画 |
| 空 / 错误状态 | 说明缺少什么并提供已有入口；保留本地数据；提示不淹没主要动作 |

## 页面应用

- 数据准备：一个保存校验主动作；资源组与表格层级清楚；JSON 和来源证据按需展开。
- 配置与运行：一个开始求解主动作；就绪原因、全局界与阶段分开，嵌套子问题进度留在事件中。
- 结果分析：共用模式及筛选；AIR / 厦航的时区与目标单位明确；当前草稿和历史快照分开。

## 验收

保留 `docs/codex_reports/assets/v3_task1` 与 `v3_task2` 的同尺寸截图；复测 1440 / 1024 / 390 × 浅深色、键盘、焦点、弹窗、表格、图表。任务1的 17 个模拟 / 3 个真实浏览器场景均继续通过；加入万行虚拟表格与厦航窄屏场景后，最终模拟浏览器检查为 20 项。自动 axe 规则通过仅表示相应自动检查通过，不替代完整人工无障碍审查。
