# Workbench v3 公开数据验证：首批结果与边界

本次已完成数据入口、HiGHS 后端、双轨审计、批量实验及 v3 复核工具，并执行冻结的首批正确性实验。**本轮算法验收未通过：A03 与飞机＋旅客案例的部分 AIR 分解路线未取得完整最优证据，后续比较、稳定性与压力实验共 372 项按协议阻止执行。** 这些任务仍在清单和统计分母中。

59 次运行通过独立方案审计并获得研究模型内最优证据，覆盖 8 个不同的冻结问题，其中若干来自同一网络；没有认证目标冲突。这不等于 59 个独立实例，也不能据此宣布算法已在公开业务模型上稳定或全局最优。

研究模型显式关闭 CRM，未生成机组或占位 `original_crew`。原机组案例继续由回归集验证。飞机模型仅包含选中活跃机尾，保留完整窗口内轮转、实际固定前缀与后缀回接，并施加硬终端边界；换机限制为相同机型、座位配置及过站时间。候选为 30 分钟网格、最大延误 120 分钟并保留原扰动关键时间点。

机场容量尚未施加；原航班串、地面交通、舱等拆分/降舱、ROADEF 原成本与维护等能力存在差异。旅客模型只优化完整落入所选航班的原始整组行程，使用单舱容量。详见[字段及规则映射](public_v3_field_mapping.md)和[工具与协议](public_benchmark_v3.md)。因此，下表目标均为冻结的 `public_air_linear_v1` 抽象成本，不是 ROADEF 官方成本。

### 列生成与分支定价的证据强度

7 个可行飞机微例在同一固定计划下，全列 LP 与 CG、终止定价核查、全列整数模型与 B&P 均一致。**7 个组件例均在根节点得到整数解，LP/IP 值均为 0，最大搜索深度为 0。** 这些证据覆盖接口、对偶/定价和简单整数一致性，尚未提供困难整数性、深分支或大规模列生成的公开证据。5 个不可行固定计划对拍保留为 inconclusive。

补充开发合同检查在实际冻结的 A01 公开输入上，于经独立审计的 incumbent 出现后触发取消：返回 aborted、保留目标 240 的合法方案与检查点，`certified_optimal=false`。见[可靠性检查](public_v3_reliability_check.json)。这验证了已有方案的保留及停止状态，不代替尚未执行的重复、节点限制、内存耗尽或大例时限实验。

J0126 在隔离 v3 存储中完成草稿、编译、不可变快照、实际 worker、方案制品和事件链验证；离线与页面接口目标同为 240，审计通过，问题指纹一致，快照环境指向正式代码 `8d2b1c7`。对原计划、扰动、恢复、差异四种视图的实际 API 读取均可用。另保留 Delft 不可行实例的 worker 终态复核，未将任务完成解释为优化可行。详见 [v3 复核记录](public_v3_first_batch/workbench_review.json)。

## 当前支持与不支持的结论

|研究问题|本轮证据结论|
|---|---|
|是否出现已认证解的目标冲突？|没有观察到；59 次认证运行覆盖 8 个冻结问题，不能外推为全部实例都正确|
|是否证明模型内最优？|上述认证运行同时具备方案审计、有限有效闭合界和算法终止证据；范围限定于研究模型与候选空间|
|AIR 主线是否通过全部微例门槛？|未通过：A03 和旅客耦合分解路线缺少最优/可行证据|
|是否优于官方历史解？|无法判断，原规则成绩可比方案为 0|
|是否稳定、高效、可扩展？|本轮尚不能回答，正式重复、网格、规模及压力阶段被阻止执行；不报告加速比或置信区间|
|可靠性是否完整验证？|停止后保留合法方案已有实际证据；其他限制行为与大例可靠性仍需后续实验|

## 根据证据安排下一轮

1. **优先定位 AIR 外层分解。** A03 的固定全列 Benders 已未收敛，而独立 Oracle、厦航路线及固定计划组件通过，首先应检查主问题必要可达域、可行计划构造与跨计划有效割，而不是直接归因于内层定价。任何强化均保留当前实现为基线并做消融。
2. **增加旅客耦合的可行解构造。** J0122 已给出合法最优参考，J0124 没有自己的 UB；优先检查初始飞机计划与原旅客组容量的联合可行性，并为每个新 incumbent 独立审计。
3. **单列不可行研究实例。** Delft 5/6 微例因固定边界及候选延误限制失去必要可达性。下一轮可预先登记额外的可行/不可行分层样本，并保留本轮全部结果；不能按求解成功与否改样或静默放宽边界。
4. **补足有整数性困难的公开微例。** 当前 B&P 根节点即整数，后续应在观察算法结果前按可审计的全列 LP/IP 间隙规则登记测试集，验证真正的分支传播与穷尽证据。
5. **补原规则能力后再讨论官方解质量。** 优先处理维护、机场容量、舱等和原成本；导出方案须通过全部原生可行性检查与成本复算，才允许关联历史成绩。
6. **修正后建立新冻结清单。** 先对本轮困难微例回归并通过门槛，再进行三次测量、跨日期、网格及压力实验。本轮证据不覆盖这些尚未运行的结论。
