## 重要字段口径

|列或列组|如何读取|
|---|---|
|任务状态／优化状态／结论|任务执行完成不表示优化可行或最优。J0125 的互操作测试 passed，但原规则检查为否；组件 passed 也不表示整体问题最优|
|是否实际执行|正式任务以真实 started.json 为依据。未执行项实际求解耗时、实际墙钟、目标、LB、UB 留空；原始状态里的 elapsed_seconds=0 单列保留|
|配置求解器／清单默认后端／清单覆盖后端|优先采用 backend_override，再采用默认值；已执行求解任务与证据 backend 逐项核对。旧简表部分 Gurobi 行沿用了默认 highs，不能用旧简表该字段判断真实后端|
|包内规模／源实例或上下文规模／任务实际规模|分别表示完整包、该原实例或载入上下文、本次入模子集，不能混用。Delft 包有 196,958 条计划，飞机字典 827 条、机场字典 160 条，不表示每个任务都使用这些资源|
|源实例航班定义数／源实例或上下文计划记录数|ROADEF 定义按日期展开为执行记录，二者可能不同。Delft 上下文是研究窗口前后各扩一天的载入记录，不是全季度|
|任务目标航班数／任务实际航班数|按完整机尾轮转闭包，实际数量可不同于目标。整窗口选择的输入哨兵值 10 亿不是航班数，目标列留空并在补充说明解释|
|任务涉及机场数／场景声明机场数|前者由入模航班起讫机场去重，后者包含输入声明的更大机场范围|
|旅客人数相关列|区分参与优化的旅客组、仅与选中航段关联的原旅客组、完整落入任务的原旅客组。人数按原行程组计数求和；航段登机人数可对同一旅客重复计数，不等于独立旅客人数|
|任务机型配置数／飞机座位／过站时间|配置包括机型、逐舱座位和过站时间；座位合计按每架选中飞机计一次，不是各航段运力合计|
|扰动相关列|ROADEF 航班、飞机、机场容量扰动分别统计；Delft 按原组合键匹配 Delay 等事件，保留原因和负延误统计。所选飞机不可用区间可能涉及上下文，不将未知 AC Unavailable 解释成机场关闭|
|资源就绪晚于首班计划的飞机数／固定资源边界摘要|本任务航班自身没有直接延误记录，也可能因已扰动的固定前缀而被迫延误。边界摘要最多展示 8 项；完整值见冻结输入|
|公开数据答案值_原规则|ROADEF 完整原实例发布的历史参考上界，非全局最优证明，单位为原评分。Delft 没有本任务配对答案；2019 只有结果分布，答案值留空，不能当 0|
|研究模型已认证最优参考值|我方对同一问题指纹获得的整体最优参考，与公开原评分分列。A03 为 240，旅客例为 93,750；不冒充未收敛路线自身的 UB。组件列为固定计划追索子目标，不能直接对比整体参考值|
|本次结果目标值／本次LB／本次UB／本次Gap_比例|来自该次运行自身；未取得合法方案的运行不填 UB。Gap 单位为比例，不是百分数文字；主动取消即使界闭合也不据此更改最优标记|
|原规则检查及官方评分|本轮原规则检查存在行程和轮转违规，没有可比较的官方成本；历史成绩差距全部留空，不以研究目标替代|
|是否仅预处理／是否实际调用优化器|5 个 Delft 问题的不可行证明来自必要可达性预处理；重复经过不同后端入口，不等于各后端完成了优化求解|
|求解入口总耗时_秒|包含该入口的枚举、构模、优化、审计等开销，不是纯求解器时间；无法拆分的分项留空|
|求解器调用累计_秒|已记录的原生优化调用累计，不包含接口构模；厦航等未单独测量的路线不填 0|
|工作进程内部耗时_秒／任务实际进程墙钟_秒|前者含任务读取和内部流程，后者另含进程启动及监护；规范化及候选生成耗时另列。最终批次的逐行墙钟之和不等于报告含旧尝试消耗的 1,983.969 秒累计预算计费|
|任务名义时限／本次入口时限／进程监护上限|分别表示登记限制、停止实验入口参数、监护进程上限。常规监护另留 45 秒，pytest 上限 600 秒；还受剩余阶段/总预算约束。约 115 秒停止的 AIR 运行由内部预算预留收尾时间|
|迭代／节点／深度／枚举上限及实际配置摘要|冻结参数或预定运行覆盖，不表示运行已触及上限。原始快照中未启用模块的参数不执行。厦航 CG 迭代上限 1000，AIR 为 100；两套路径 Oracle 上限也不同。迭代停止任务请求阈值 1，但未执行，不能据此声称已验证生效|
|能力预检缺口／问题原因|未执行的直接原因是前置门槛；维护和不可用语义等次要能力缺口另列。具体算法根因尚未证实时明确标记为待定位|
|路径、输入／结果／配置／候选 SHA256|均指向原始证据；相对路径以仓库根目录为起点。源文件清单内路径相对于其数据包。基础冻结输入和按算法/后端改写后的执行输入哈希分列|

空白单元格表示未知、未执行或不适用，原因通过邻近状态和说明列给出；数值 0 保留为真实数值。所有时长单位为秒，延误单位为分钟，旅客加权延误单位为人分钟。部分证据使用源文件时区，开始/结束时间另转换为北京时间。

## 来源与重新生成

依据[验证报告](public_v3_results.md)、正式 manifest/registry/state、逐次 input/evidence/started/checkpoint、原始旅客及扰动字段、官方历史参考表和 2019 提取证据整理；并非仅手抄报告表格。

```powershell
python scripts/export_public_benchmark_tasks.py
```

生成器只读原实验资料，不重新求解，不覆盖正式批次证据。输出前检查任务唯一性、原始文件哈希、正式状态分布、后端覆盖、关键 LB/UB 和停止合同；保存后重新解析 CSV 核对行列结构。此次也验证了 UTF-8 BOM、所有单元格长度及 Excel 公式注入前缀。
