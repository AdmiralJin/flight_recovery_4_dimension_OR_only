# v3 公开基准验证实施协议

基线：`fa293d3ba556f1e5ae621e1eee0bcb8dadab00b2`（`workbench-v3-optimized`）。分支：`feature/public-benchmark-v3-validation`。本文件记录用户批准的计划，正式任务清单另行冻结精确时间、输入与配置哈希。

- 双轨：原规则外评与统一 AIR 研究模型分别报告。历史最好成绩不是最优性证明；Delft 2019 结果不与 2020 输入强行配对。
- 数据：ROADEF 32 例；Delft 2019 六份结果表；Delft 2020 季度输入。保留原件、来源行、SHA256、窗口边界和规则缺口。
- 仅使用公开字段，不生成机组。公开模型分别为飞机恢复、飞机与旅客恢复；机组继续使用既有回归。
- 主线：AIR Benders/CG/B&P；对照：Integrated Oracle、固定列 Benders、飞机全列 LP/MIP及厦航四路线。仅相同问题指纹可对拍。
- 新增 HiGHS SolverAdapter；小例与 Gurobi 交叉核验 LP/MIP、对偶、界与停止状态。
- 原规则外评：ROADEF 导出与官方检查器；仅通过完整检查的方案进入历史成绩比较。统一成本与原始成本分别保存。
- 微例：每个输入来源至少六例；规模目标 20/50/100，再到500及完整实例。Delft 采用12小时研究窗口，不冒称原370组。
- 默认网格30分钟、最大延误120分钟；网格对照60/30/15分钟。性能预热一次、正式三次，种子固定。
- 首批运行24小时：正确性2h、对照8h、稳定性6h、压力8h；单例120/300/300/1800秒。性能独占、单线程；轻任务至多并发2，重任务进程树6GiB上限。
- 最优判定需要独立审计、有效全局LB/UB闭合及定价/搜索证据。超时、资源限制、预算未运行均保留，不自动简化问题。
- 交付：解析、预检、执行、续跑、报告工具；冻结清单及证据；v3代表草稿与审计复核；阶段总结。

原始大文件不提交Git。每阶段按北京时间时间戳写入本目录。先通过正确性门槛，再派发性能与压力任务。
