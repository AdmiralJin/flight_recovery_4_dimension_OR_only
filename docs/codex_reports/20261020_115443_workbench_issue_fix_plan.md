# Workbench 问题修复计划总结

## 计划范围

- 明确内置 Case 克隆、草稿导入和当前草稿切换的界面语义。
- 修复终态历史 Run 未回载 Trace、上下界和 Gap 的问题。
- 以可视化页 Impact 航班时空图为标准统一扰动影响页。
- 修正成本、延误图未响应 Original、Impact、Recovered、Delta 模式的问题。
- 补充厦航 Gurobi 与 HiGHS 求解过程事件，分析并优化约 100 航班模型性能。
- 增加前后端自动化测试、规模基准和用户指南说明。

## 实施原则

- 先修复状态与证据展示，再统一图形，最后开展求解性能优化。
- 不伪造求解进度或上下界；后端无法提供实时界时明确显示求解器和可观测性限制。
- 所有历史结果继续绑定不可变快照和 Input hash。
- 性能优化必须保持独立审计、可行性和目标函数一致性。

## 待确认事项

- 建议 Original 与 Impact 模式不展示恢复成本和实际延误，显示“该模式不适用”；Recovered 展示求解结果；Delta 展示相对原计划的增量。实施前需确认该业务语义。
