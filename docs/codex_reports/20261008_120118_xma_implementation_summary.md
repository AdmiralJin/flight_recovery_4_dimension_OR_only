## 规模实验与未解决事项

同候选、同15秒限制，直接模型30/103航班获得审计通过的最优解；508航班短时未获得完整incumbent。两个分解版本在真实子集短时未收敛，保存真实下界和终止原因。条件值割较弱，尚无分解优于直接模型的性能结论。

全量、60分钟步长、最大延误120分钟需要361810个飞机分配组合，默认100000保护值明确拒绝且不截断候选。补充显式提高规模上限的全量零延误实验：网络流构模727746变量/625245约束耗尽短预算；Benders主问题认证零延误候选不可行。此结果不代表允许充分延误的完整恢复问题不可行。全量恢复最优解尚未取得，需要继续规模/时限、有效割、热启动及候选加密研究。
