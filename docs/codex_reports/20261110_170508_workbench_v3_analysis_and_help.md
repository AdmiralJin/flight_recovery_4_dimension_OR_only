## 本轮改动

1. 删除重复「总览」标签，默认进入「航班与资源」；唯一独有的「方案对比与资源汇总」迁入该页，按需加载及导出能力保留。
2. 当前运行新增独立墙钟组件，每秒刷新，不依赖事件频率；排队单独标识，刷新后根据后台时间恢复，结束后固定。时钟更新不触发图表重绘。禁用的开始求解按钮显示灰色，重复提交保护保留。
3. 新增统一 Tooltip（悬浮提示），包含 109 项显式关键词解释及标识符、时间等补充规则，覆盖表单、指标、筛选、模式、表头及审计。支持悬停、键盘聚焦、点击与 Esc；长说明可滚动，同时只保留一个提示。
4. 目标函数显示 AIR 总成本分解、当前覆盖系数，或天池评分及其分段延误公式；算法说明随选择变化。AIR 未覆盖的系数明确标记为基准配置，不编造数值，实际取值以审计快照为准。
5. 图表从完整模型生成坐标域及机场、资源索引，再遮罩筛选数据；筛选为空也保留坐标。横纵轴分别支持滑块和按钮缩放，保留手动范围。补齐换机蓝色、换组、取消、置位、地面行程等图例，颜色使用绘图同一调色板。
6. 航班提示增加原计划、恢复时刻、延误、资源、扰动规则及旅客关联；甘特增加旅客人数、未服务量、资源状态与航段；容量增加方向、时间窗、负荷及利用率；成本增加单位、总额与占比。输入文本做 HTML 转义。

成本和机场容量保持完整运行的统计口径，不因航班筛选重新计价或分摊。传播图仍表示风险关联。

## 「证明最优」的含义

针对本次模型、实际候选空间及数值容差：经审计的完整可行方案给出上界 UB，有效松弛、割、定价或搜索证据给出下界 LB；两者闭合才证明最优。列生成还需定价终止证据，不能把受限主问题或内部子问题的界直接当全局界。

页面标签映射后端优化状态，本轮未改变算法认证条件。复核应同时查看全局界、独立审计及定价证据；标签不扩大结论到未生成候选或模型之外的真实业务。
