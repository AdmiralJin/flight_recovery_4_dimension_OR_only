# 厦航接入阶段总结 05_decomposition

2026-10-08 11:55:30 北京时间

实现航班主问题+联合飞机旅客子问题的Logic-based Benders。仅认证不可行才生成精确日程禁割，认证子问题成本下界生成非负追索的有效条件值割。固定日程联合子问题使用飞机路径列生成，人工变量PhaseI完整定价后才判LP不可行，PhaseII关闭人工变量。

DAG定价包含分配联动、终点、联程、停机的对偶贡献，不全枚举路径。分支节点优先飞机分配，再处理剩余人数/其他整数变量，每个节点重新定价。验证四架构双目标一致、非零延误一致、拆分改签一致、HiGHS对偶/整数结果一致，以及真正需要多分支的实例和节点限制下界。实际条件割较弱，真实子集短时未收敛，不宣称分解更快。
