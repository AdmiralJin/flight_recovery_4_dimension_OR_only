# 厦航工作台下一步计算与验证

北京时间：2026-10-08T14:23:49+08:00

本次核对当前工作台按钮、配置字段与结果语义，给出用户可执行的首次验证步骤。未修改代码、原始数据或求解参数，未启动新的求解。

1. 数据设计→厦航数据与求解配置，选约20航班→读取项目厦航数据→创建厦航研究草稿。整轮转实际为30航班。
2. 目标选择天池评分（数据包源码），算法选择直接联合优化，延误步长60分钟、最大延误120分钟、时限30秒，飞机分配规模上限保持默认。数字修改后移开焦点触发保存。
3. 扰动影响→编译并预览。Ready仅代表输入检查通过，不代表已证明存在可行解。
4. 求解→创建快照并求解，运行Profile先保持默认。completed仅表示运行结束，需看Optimization及结果。
5. 厦航恢复与旅客分配→逐项评分与独立审计，检查valid=true、已占座≤实际座位、成本与上下界。最优仅限当前候选；取消、未服务在首版规则允许范围内，不要求其人数为0。
6. 约20跑通后再约100，然后约500/全量；比较分解算法时保持输入、目标和候选参数相同。

结果解释：optimal且独立审计通过表示已有合法解并证明当前候选最优；not_converged若有完整审计通过方案则已有可行解但未证最优，没有方案则尚未知是否有解；infeasible仅证明当前候选与规则下无解；failed/Blocked表示运行或输入问题。全量仍有规模和时限限制，不以一次超时推论无解。
