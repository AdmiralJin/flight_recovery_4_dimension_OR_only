# Workbench v3 简明使用指南

更新：2026-11-10。适用于当前 v3 界面，支持 AIR 与厦航研究数据。

## 1. 打开工作台

在项目根目录执行（使用已安装项目依赖的 Python 环境），并保持此终端运行：

```powershell
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

看到服务启动成功后，单击终端显示的 <http://127.0.0.1:8000> 即进入 v3；部分终端需要按住 Ctrl 再单击。已有服务运行时，更新后先按 Ctrl+C 停止，再执行上述命令启动。

v3 专用地址为 <http://127.0.0.1:8000/static/workbench-v3/index.html#/prepare>。要切回 v2，打开 <http://127.0.0.1:8000/workbench-v2/data>。若缺少 v3 构建产物，首页会回退到 v2 或旧版页面。

若 v3 页面不存在或更新后未生效，在 `frontend` 目录执行 `npm run build:v3`，再刷新浏览器。不要直接双击 HTML 文件。右上角可切换浅色、深色主题。

## 2. 数据准备：创建、编辑、校验

点击 **新建 / 导入**，选择来源：

| 来源 | 操作 |
|---|---|
| Case 库 | 选择案例，点击「克隆为草稿」；初次体验可从这里开始。 |
| 厦航数据 | 使用项目数据或上传 `.xlsx`，选择固定子集或随机抽样、目标规模与种子；点击「生成导入预览」，核对后点击「使用预览创建草稿」。实际航班数以完整机尾抽样结果为准。 |
| JSON 导入 | 导入工作台导出的草稿 JSON，创建独立副本；格式版本为 `2.0.0`。 |
| 空白草稿 | 创建后自行补齐数据、恢复窗口与候选。 |

顶部下拉框切换当前草稿。在 **数据资源**、**扰动与容量** 中选择数据类型，点击表格记录编辑常用字段；标识符默认只读。复杂结构在 **高级数据 → 完整草稿 JSON** 中编辑，点击「应用到编辑副本」后保存。

- **仅保存**：保存数据及已修改配置，不生成候选、不执行校验；适合编辑过程中暂存。
- **保存并校验**：保存后生成候选并检查输入；到 **校验预览** 查看错误位置、扰动影响和候选数量。
- 数据或配置修改后，原校验立即失效。切换工作区保留编辑；切换草稿等操作遇到未保存修改时，可选择保存、放弃或取消。
- **导出草稿** 可保存当前编辑副本，之后通过 JSON 导入复用。

## 3. 配置与运行：校验后开始求解

1. 进入 **配置与运行**，设置目标、算法、候选和时限。
   - **AIR**：使用 Benders＋Branch & Price 路线；选择运行参数模板，可调整时限、迭代及分支节点上限。
   - **厦航**：选择天池评分或 AIR 研究成本，以及直接联合优化、显式航班串 Oracle、Benders＋联合子问题、Benders＋列生成 / 分支定价。Oracle 用于小实例。
2. 点击 **保存并校验**。若「开始求解」不可用，按 **开始前需要处理** 中的原因修正。
3. 点击 **开始求解**。系统建立不可变输入快照，再提交后台任务；等待时查看页面显示的保存、校验、快照或提交阶段，避免重复点击。
4. 在 **当前运行** 查看状态、全局 LB、UB、Gap 和收敛轨迹。展开 **运行事件与技术证据** 查看细节或导出事件；无全局界时，查看构模、定价等事件。
5. 需要停止时点击 **取消运行**，等待状态确认。通过 **运行历史** 可重新选择记录；勾选「全部草稿」查看其他草稿的运行。

切换页面、刷新或关闭浏览器不会主动取消已提交的求解；重新打开后可从历史记录恢复查看。后台服务需保持运行。后续编辑草稿不会改变已有运行快照。

运行耗时每秒更新，结束后固定；开始求解后按钮会禁用并显示灰色。字段和指标旁的 **小问号（Tooltip 悬浮提示）** 支持鼠标悬停、键盘聚焦和点击；按 Esc 收起。目标函数显示表达式与计分口径，算法说明随当前选择更新。

## 4. 结果分析：确认来源，再看方案

先选择 **分析来源**：

- **当前草稿**：查看最近保存的输入，不包含尚未保存的编辑。
- **运行快照**：选择具体运行记录，查看该次求解的方案和证据。

按需切换 **原计划、扰动影响、恢复方案、变化对比**；不可用模式会禁用并提示原因。

| 视图 | 用途 |
|---|---|
| 航班与资源 | 已合并原「总览」，保留「方案对比与资源汇总」。切换航班时空、飞机甘特、机组甘特、扰动传播；按机场、变化状态等筛选，点击图表或表格查看实体证据。 |
| 旅客与容量 | 查看旅客行程及机场容量；厦航有分配结果时，可导出天池 11 列 CSV。 |
| 成本与延误 | 查看成本构成、延误及航班明细。 |
| 审计与导出 | 查看输入、决策、上下界和独立审计，导出完整审计包；需选择运行快照。 |

顶部 **导出当前模型** 保存可视化模型 JSON；需要复核求解结论时使用 **导出完整审计包**。AIR 时间按 UTC，厦航按北京时间显示；AIR 研究成本与天池评分分别比较。

筛选只改变显示对象，横纵坐标保持完整模型范围。使用底部、右侧滑块，或在图下选择「横轴 / 纵轴」再点击放大、缩小、复位；筛选保留手动缩放。悬停图形可查看原计划与恢复时刻、资源、旅客数量、容量或成本占比。成本总额与机场容量采用全局口径，不按航班筛选重新计价或分摊。

## 5. 读懂状态与处理问题

- **证明最优**：针对本次模型、实际候选范围和数值容差。合法完整方案给出 UB，有效松弛、割及定价/搜索证据给出 LB，两者闭合才证明最优；页面标签来自后端状态，应在审计中核对方案、全局界及定价终止证据。
- **合法可行**：已有合法方案，尚未证明最优。
- **认证不可行**：当前模型无可行解，检查资源、候选及冲突约束。
- **未收敛 / 达到时限**：查看上下界与审计；可能保留经审计的可行方案，不能直接视为最优或不可行。
- **执行完成** 只表示任务结束，具体结论以优化状态和审计为准。
- **版本冲突**：本地修改会保留；先导出本地副本，再重新载入服务器版本。
- **操作等待较久**：先查看当前阶段、耗时和事件。候选越密、规模越大，校验与求解通常越慢；初次使用可从小样本开始，再逐步扩展。
