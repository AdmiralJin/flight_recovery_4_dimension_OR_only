    WORKBENCH FLOW

    How to run a case

    1. Load or Import. Select a repository example and click Load Case, or import a Scenario / Solve Bundle / Snapshot JSON.
    2. Check Solve input. READY means the Scenario has usable recovery columns, capacity data, cost/profile configuration and passes input-readiness checks.
    3. Inspect if needed. Use Validate, Visualization, Costs and Constraints before solving. Precheck verifies input consistency; it does not prove MIP feasibility.
    4. Solve. Click Solve only when the readiness indicator is READY. The UI locks mutable inputs while the synchronous exact solve is running.
    5. Review Recovery. Open Recovery to inspect objective components, changed flights, resources, passengers and diagnostics.

    Scenario-only: a valid Scenario can still be non-solve-ready. The Workbench will automatically attach matching repository Columns and Capacity when compatible fixtures exist. Otherwise the page will state which solve inputs are missing.
